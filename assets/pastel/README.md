# Clavis pastel UI illustration set

Generated with the built-in imagegen tool. All six PNG assets have genuine alpha transparency. Original Clavis home illustrations, navigation icons, application logo, taskbar icons, publisher logos and book cover images are preserved. The corresponding UI surfaces are defined in `ui/pastel.css`; reusable placements are defined in `src/illustrations.js`.

## Prompt set

The exact common prompt used for downloads, feeds, settings, search and bookmarks:

> Production-ready single transparent PNG UI illustration for Clavis book/audiobook app, square canvas, isolated centered object occupying 76% with transparent padding. Soft pastel rounded geometric forms, smooth curves and softly rounded corners. Gently sculpted matte dimensional depth, delicate gradients and soft upper-left highlights, restrained shading only along edges and overlaps. Bold clear silhouette readable at 64 px, minimal broad shapes, consistent object scale. Palette cream #F7EBDD lavender #C8C1E7 dusty indigo #7971AE peach #EDB5A5 sage #BBD4C8. No text, letters, numbers, outlines, glossy reflections, strong shadows, background, or scattered decorations. Coordinate with a pastel book-storage tray and existing peach book/headphone icons.

Each common prompt was followed by its subject:

- **downloads.png:** Subject: a rounded lavender download tray with a thick sage downward arrow and one cream document sheet, tiny peach page corner. Represents downloads and imports.
- **feeds.png:** Subject: two overlapping rounded cream article cards with a lavender folded corner, and one simple peach RSS broadcasting symbol in front, only two broad signal arcs. Represents live RSS news, journals and podcasts.
- **settings.png:** Subject: three rounded lavender vertical adjustment sliders on a small softly rounded cream panel, sage and peach circular knobs. Represents app preferences and equalizer.
- **search.png:** Subject: one large rounded lavender magnifying glass with a peach handle, resting across one small cream book with sage spine. Represents search or no search results.
- **bookmarks.png:** Subject: one softly rounded cream open book with a wide peach ribbon bookmark tucked over its central fold, sage page edge and restrained lavender overlap shading. Represents saved reading moments and journal writing.

The exact library prompt:

> Create one production-ready transparent PNG UI illustration for Clavis, a calm book/audiobook Windows app. Subject: a small open lavender storage tray holding two rounded cream books, one sage-green book, and a single peach bookmark. This asset represents an empty library waiting for imports. Centered isolated composition, square canvas, object occupies 76% of canvas, generous transparent padding. Soft pastel illustration style with rounded geometric forms, smooth curves, gently softened corners. Subtle dimensional depth through delicate gradients, soft highlights from upper left, restrained shading along folds, edges and overlapping surfaces. Matte softly sculpted finish; no glossy reflections, strong shadows, dramatic lighting, outlines, lettering, words, background, or decorative speckles. Bold recognizable silhouette at 64 px, few broad shapes and minimal internal detail. Palette cream #F7EBDD, lavender #C8C1E7, dusty indigo #7971AE, peach #EDB5A5, sage #BBD4C8. Coordinate with existing pastel peach headphones-and-book icons, do not recreate or alter them.

`original-icons.sha256.json` records the original icon hashes for preservation checks.
