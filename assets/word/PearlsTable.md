# Pearls Table

Approved from the CH50/AH50 table screenshot on 18 November 2026.

- Header: pale mauve E7E1E4, bold plum text 5C3A52.
- Body: alternating F8F6F8 and white, black text.
- Borders: D9D9D9, 0.5 pt.
- Font: Averia Serif Libre, 9.5 pt.
- Cell margins: top/bottom 3.25 pt; left/right 4 pt.
- Paragraph spacing: 1.2 pt before, 2.4 pt after, line value 249.
- Repeat the first row; keep the header with the following row and avoid splitting rows.

The native Word table style is named **Pearls Table**, ID `PearlsTable`.
`PearlsTable.xml` is the reusable style definition. Column widths, merged cells,
clinical text, equations and images are preserved when applying the style.
